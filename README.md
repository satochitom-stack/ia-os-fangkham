## 🔐 ระบบ Login (ผู้ใช้คนเดียว)

* เข้าใช้งานครั้งแรกจะเจอหน้า **"ตั้งค่าบัญชีผู้ใช้ครั้งแรก"** ให้ตั้งชื่อผู้ใช้และรหัสผ่านเอง (ไม่มีบัญชีเริ่มต้นมาให้ — ต้องจดจำเอง เพราะไม่มีระบบกู้คืนรหัสผ่าน)
* ข้อมูลบัญชี (username + salt + SHA-256 hash ของรหัสผ่าน) เก็บใน LocalStorage คีย์ `ia_auth_account` ของเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ส่งออกไปที่ใด
* เปลี่ยนชื่อผู้ใช้/รหัสผ่านได้ภายหลังจากเมนูมุมขวาบน (คลิกที่ชื่อผู้ตรวจสอบ → "เปลี่ยนชื่อผู้ใช้ / รหัสผ่าน")
* หากลืมรหัสผ่านและไม่มีทางกู้คืน วิธีแก้คือลบคีย์ `ia_auth_account` และ `ia_auth_session` ออกจาก LocalStorage ของเบราว์เซอร์ (Developer Tools → Application → Local Storage) แล้วตั้งค่าบัญชีใหม่

## 📊 Export Excel

* ปุ่ม **"Export Excel"** อยู่ในโมดูล Execution (กระดาษทำการ) จะดาวน์โหลดไฟล์ `.xls` ที่จัดรูปแบบเหมือนกระดาษทำการจริง (หัวกระดาษ, เกณฑ์การตรวจ, ตาราง Checklist, ตารางสุ่มตรวจตัวอย่าง, สรุปข้อตรวจพบ 4 องค์ประกอบ)
* ใช้เทคนิค HTML table ฝังในไฟล์ `.xls` (Excel เปิดได้โดยตรง) จึงไม่ต้องติดตั้งไลบรารีเพิ่มเติมและไม่ต้องมีอินเทอร์เน็ต

## 🌗 Dark Mode

* ปุ่มรูปพระอาทิตย์/พระจันทร์ที่ Header สลับโหมดสว่าง/มืด บันทึกค่าไว้ใน LocalStorage คีย์ `ia_dark_mode` และจดจำการใช้งานครั้งถัดไป

## 📁 ไฟล์แนบจริงในคลังระเบียบ (Knowledge Base)

* ไฟล์เอกสารอ้างอิงจริง (พ.ร.บ./ระเบียบ/หนังสือสั่งการ ที่มีขนาดเหมาะสม) ถูกคัดลอกมาไว้ที่ `public/knowledge/` เพื่อให้เปิด/ดาวน์โหลดได้จริงจากปุ่ม **"เปิดไฟล์"** ในการ์ดแต่ละรายการของโมดูล Knowledge Base
* รายการที่ยังไม่มีไฟล์แนบจะแสดงข้อความ **"ไม่มีไฟล์แนบในระบบ"** อย่างตรงไปตรงมา แทนป้าย "มีไฟล์ในระบบ" แบบเดิมที่ขึ้นเสมอโดยไม่มีไฟล์จริงรองรับ
* โครงสร้างข้อมูลใน `initialKnowledgeBase` เพิ่มฟิลด์ `fileUrl` (และ `fileUrl2` สำหรับรายการที่มี 2 ไฟล์ เช่น เงินอุดหนุน .pdf + .xlsx) ชี้ไปยังไฟล์ใต้ `public/knowledge/`

## 🎯 7 โมดูลหลักในระบบ

1. **Dashboard**: สรุปสถิติ 4 มิติ (แผนตรวจสอบ 7 เรื่องตามแผนประจำปี, LPA 25 คะแนน, ควบคุมภายในส่งครบ 6 กอง, ความเสี่ยงสูง KTB Online)
2. **Planning**: กฎบัตรการตรวจสอบภายใน 2568, เครื่องคำนวณและผังความเสี่ยง 5x5 Matrix, ตารางแผนประจำปี (7 เรื่อง รวมการตรวจสอบเงินอุดหนุน)
3. **Execution**: กระดาษทำการตรวจ (KTB Online, ค่าเช่าบ้าน, จัดซื้อจัดจ้าง, **เงินอุดหนุน — เช็กลิสต์ 20 ข้อตามระเบียบ มท. ว่าด้วยเงินอุดหนุนฯ พ.ศ. 2559**) มี Checklist 3 สถานะ, สุ่มตรวจฎีกา/โครงการ, บันทึกข้อตรวจพบ 4 องค์ประกอบ (Condition, Cause, Effect, Recommendation) พร้อมปุ่มพิมพ์และปุ่ม **Export Excel**
4. **Reporting**: ร่างบันทึกข้อความรายงานผลส่งนายกฯ/ปลัด, วาระประชุมปิดตรวจ, กระดานติดตามข้อเสนอแนะ
5. **Control & Risk**: แบบ ปค.4 (ประเมิน 6 ส่วนราชการ), แบบ ปค.5, แบบ ปค.1, แบบ บส.1-5
6. **LPA Readiness**: ตัวชี้วัด 1-5 ด้านที่ 1 การบริหารจัดการ พร้อม Evidence Checklist คำนวณคะแนนสด
7. **Knowledge Base**: ค้นหาหนังสือสั่งการ (ว 119, ว 257, ว 11807, พ.ร.บ. วินัยการเงินการคลัง, พ.ร.บ. จัดซื้อจัดจ้าง, ระเบียบเงินอุดหนุนฯ 2559)

ครอบคลุมด้วยระบบ **Login คนเดียว** (ดูหัวข้อ 🔐 ด้านล่าง), ปุ่ม **Export Excel** ในกระดาษทำการ, และ **Dark Mode** ทั่วทั้งระบบ
