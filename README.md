# ระบบปฏิบัติการตรวจสอบภายใน อปท. (Internal Audit Operating System - IA-OS)

เว็บแอพพลิเคชันเพื่อสนับสนุนและยกระดับการปฏิบัติงานตรวจสอบภายในสำหรับองค์กรปกครองส่วนท้องถิ่น (อปท.)  
**หน่วยงานต้นแบบ:** หน่วยตรวจสอบภายใน องค์การบริหารส่วนตำบลฝางคำ อำเภอสิรินธร จังหวัดอุบลราชธานี  
🌐 **ระบบออนไลน์ (Production):** [ia-os-fangkham.vercel.app](https://ia-os-fangkham.vercel.app/)

---

## 📢 บันทึกการปรับปรุงระบบล่าสุด (Release Notes - 22 กันยายน 2569 • v2.4.0)

### 1. 🏛️ ข้อมูล อปท. และปีงบประมาณตั้งต้น (Default Fiscal Years & Org Profile)
* **ปีงบประมาณเริ่มต้น:** กำหนดเป็น **ปี 2569 และ ปี 2570** พร้อมระบบ Migration และจัดเก็บข้อมูลลง LocalStorage อัตโนมัติ ป้องกันการสูญหาย
* **ข้อมูล อปท. ตั้งต้น:**
  * **หน่วยงาน:** องค์การบริหารส่วนตำบลฝางคำ
  * **อำเภอ/จังหวัด:** อำเภอสิรินธร จังหวัดอุบลราชธานี
  * **นายก อปท.:** นายจรูญ ธรรมพิทักษ์
  * **ปลัด อปท.:** นายชาญชัย อักโข
  * **ผู้ตรวจสอบภายใน:** นายศุภมงคล ธรรมพิทักษ์ (นักวิชาการตรวจสอบภายในปฏิบัติการ)
* **โครงสร้างสำนัก/กอง:** เชื่อมโยง **กองสวัสดิการสังคม** เป็นกองหลักของ อบต.ฝางคำ และปรับปุ่มเข้าสู่ระบบของผู้ดูแลระบบเป็น **"หน่วยตรวจสอบฯ"**

### 2. 🛡️ ระบบกำหนดสิทธิ์รายกอง (Multi-User RBAC Permission Matrix)
* **ปุ่มบันทึกและยกเลิก:** เพิ่มปุ่ม **"บันทึกการเปลี่ยนแปลง"** และปุ่ม **"ยกเลิก"** ในหน้าตารางกำหนดสิทธิ์รายกอง (Permission Matrix)
* **หน้าต่างยืนยันการบันทึก (Confirmation Modal):** ระบบจะไม่บันทึกอัตโนมัติทันทีที่ติ๊กเลือก เพื่อป้องกันการแก้ไขผิดพลาด โดยจะมีหน้าต่างแจ้งเตือนสรุปการเปลี่ยนแปลงให้ผู้ดูแลระบบกดยืนยันอีกครั้ง

### 3. ✨ การปรับโฉมหน้าแรก / หน้าต้อนรับ (Hero 3D Spline & Typography)
* **Spline 3D Scene:** บูรณาการคอมโพเนนต์ 3D Interactive Scene แบบลอยตัวลื่นไหล
* **White Spotlight Effect:** ปรับแต่งดวงแสงสีขาวเคลื่อนที่ตามเมาส์ให้สว่าง ชัดเจน ไร้อาการหน่วง และปรับขนาดดวงแสงเป็น 280px เพื่อความสมดุลสวยงาม
* **Modern BOT HUB Typography:** ใช้แบบอักษรทันสมัย (Prompt / Plus Jakarta Sans / Sarabun) พร้อมตัดคำว่า "ยุคดิจิทัล", "Architecture" และคำบรรยาย SOFCK ออกเพื่อความกระชับ ตรงประเด็น
* **ปุ่มบันทึกประวัติการปรับปรุง:** เพิ่มปุ่มและหน้าต่างป็อปอัปแสดง Release Notes ในหน้าแรกและเมนูผู้ใช้งาน

### 4. 💾 ความเสถียรของฐานข้อมูล (Data Persistence & Sanitization)
* แก้ไขปัญหาข้อมูลที่เคยแก้ไขหรือลบปีงบประมาณแล้วเด้งกลับเป็นค่าตั้งต้นเดิมเมื่อมีการ Deploy ระบบใหม่
* ระบบ Fallback Sanitization อัปเกรดฐานข้อมูลในเบราว์เซอร์เก่าให้ตรงกับข้อมูลจริงของ อบต.ฝางคำ ทันที

## 🎯 โมดูลหลักในระบบ IA-OS (10 โมดูล)

1. **🌟 Welcome & Hero Landing Page:** หน้าแรกแนะนำระบบงาน ออกแบบสไตล์ล้ำสมัยด้วย Spline 3D Scene, Quick Login รายกอง และสรุปภาพรวม
2. **📊 Dashboard:** ภาพรวมสถานะงาน สถิติการตรวจ 4 มิติ, ติดตามฎีกา/โครงการ และปฏิทินงานตรวจสอบ
3. **🎯 การประเมินความเสี่ยง (Audit Risk Universe):** 
   * บรรจุ **21 กิจกรรมตรวจเฉพาะของ อบต.ฝางคำ** ครอบคลุมทุกสำนัก/กอง
   * คำนวณความเสี่ยงด้วยสูตร 5 ปัจจัย (SOFCK Matrix) อัตโนมัติ จัดลำดับ สูงมาก-สูง-ปานกลาง-ต่ำ
   * ตารางเปรียบเทียบการควบคุมภายใน (IC) vs การตรวจสอบภายใน (IA)
4. **📋 แผน & นโยบายการตรวจ (Planning):** 
   * กฎบัตรการตรวจสอบภายใน (Internal Audit Charter) ประจำปีงบประมาณ
   * แผนการตรวจสอบระยะยาว (3 ปี)
   * แผนการตรวจสอบประจำปี (Annual Audit Plan)
5. **⚡ แผนปฏิบัติงานตรวจสอบเฉพาะเรื่อง (Engagement Plan - ว 614):**
   * จัดทำตามหนังสือกระทรวงการคลัง ที่ กค 0409.2/ว 614
   * มีระบบ **AI Copilot** ช่วยร่างวัตถุประสงค์ ขอบเขต และขั้นตอนการตรวจสอบ
   * บันทึกแจ้งกำหนดการเข้าตรวจและหนังสือขอความอนุเคราะห์ข้อมูล
6. **📝 ปฏิบัติการตรวจ & กระดาษทำการ (Execution):**
   * กระดาษทำการมาตรฐาน (Checklist 3 สถานะ, สุ่มตรวจตัวอย่างฎีกา)
   * สรุปข้อตรวจพบ 4 องค์ประกอบ (Condition, Cause, Effect, Recommendation)
   * **Export Excel (.xls):** ส่งออกเป็นไฟล์ Excel ที่จัดรูปแบบพร้อมใช้งาน
7. **📑 รายงาน & ติดตามผล (Reporting):**
   * ร่างบันทึกข้อความรายงานผลการตรวจสอบต่อนายก อปท. และปลัด อปท.
   * วาระการประชุมปิดตรวจ (Exit Conference)
   * กระดานติดตามผลการปฏิบัติตามข้อเสนอแนะ (Audit Follow-up)
8. **🛡️ การควบคุมภายใน & บริหารความเสี่ยง (Control & Risk):**
   * แบบประเมิน ปอ.1, ปอ.2, ปอ.3, ปค.4 (6 ส่วนราชการ) และ ปค.5
   * รายงานการบริหารจัดการความเสี่ยง (แบบ บส.1 - บส.5)
9. **🏆 เตรียมรับประเมิน LPA (LPA Readiness):**
   * ตัวชี้วัดที่ 1-5 ด้านการบริหารจัดการ อปท.
   * เช็กลิสต์หลักฐานอ้างอิง พร้อมคำนวณคะแนนประเมินสด
10. **📚 คลังระเบียบ & แบบฟอร์ม (Knowledge Base):**
    * คลัง พ.ร.บ., ระเบียบกระทรวงมหาดไทย, และหนังสือสั่งการสำคัญ (ว 119, ว 257, ว 11807 ฯลฯ)
    * รองรับการดาวน์โหลดไฟล์แนบจริงในระบบ

## 💻 Tech Stack & การติดตั้ง

* **Frontend:** React 19, Vite 8, TypeScript / JavaScript JSX
* **Styling:** Tailwind CSS v4, Lucide React Icons
* **3D Visuals:** Spline Tool (`@splinetool/react-spline`)
* **Typography:** Prompt, Plus Jakarta Sans, Sarabun (Google Fonts)
* **Data Storage:** Client-side LocalStorage with Auto-migration & Backup/Restore (JSON)
* **Deployment:** Vercel Production Continuous Deployment

### คำสั่งสำหรับนักพัฒนา
```bash
# ติดตั้ง dependencies
npm install

# รันเซิร์ฟเวอร์สำหรับพัฒนา (Development)
npm run dev

# บิลด์สำหรับใช้งานจริง (Production Build)
npm run build
```
